# Формат bundle 2

Формат 2 введён в `bundle.py 0.2.0`. Bundle остаётся Markdown-документом, но каждый запуск `-o`, вывод в stdout или добавление `-a` создаёт самостоятельный фрагмент.

## Границы фрагмента

```markdown
<!-- bundle:fragment:start -->
<!-- bundle:format=2 -->
<!-- bundle:generator=bundle.py version=0.2.0 -->
...
<!-- bundle:fragment:end -->
```

При `-a` старые фрагменты не пересчитываются. Новый фрагмент получает собственные метаданные и manifest.

## Метаданные

Если не указан `--no-metadata`, поля записываются в стабильном порядке:

```text
Repository: <абсолютный путь корня Git-репозитория или bundle root>
Bundle root: <абсолютный корень, переданный программе>
Branch: <ветка, detached HEAD или not-applicable>
Commit: <полный SHA или not-applicable>
Generated at: <ISO 8601 с timezone>
Git status: clean|dirty|not-a-git-repository
Bundle generator/version: bundle.py <версия>
Included files count: <число файловых записей>
```

При `dirty` следует список `Uncommitted files`. В `Included files count` входят обычные, бинарные и `--paths-only`-файлы; каталоги и служебные блоки не входят.

## Идентификаторы записей

Каждая запись содержит машинный блок:

```text
Kind: internal|external
Key: i:<encoded-path>|e:<encoded-path>
Path: "<читаемый путь>"
Repository path: "<путь внутри Git-репозитория>"  # когда применимо
Type: text|binary|path-only|directory
Size: <исходный размер>                            # для содержимого
```

Внутренние пути относительны `Bundle root`. Внешний путь также хранится относительно `Bundle root`, например `../trash/file.txt`; абсолютный исходный путь ОС не сохраняется. Абсолютный CLI-ввод сначала преобразуется в относительный путь. Если это невозможно, например между дисками Windows, создание завершается ошибкой.

`Key` начинается с `i:` или `e:`. Небезопасные символы и Unicode кодируются percent-encoding, поэтому реальные имена `__external__`, `__parent__`, `i:`, `e:`, `%` и `:` не конфликтуют со служебным форматом.

## Manifest

Если не указан `--no-manifest`, фрагмент завершается разделом:

```text
<sha256>  <entry-key>
```

SHA-256 вычисляется по исходным байтам до декодирования, нормализации строк и Base64. Текст, Base64 и checksum строятся из одного чтения файла. В manifest входят только обычные текстовые и бинарные файлы. Каталоги, `--paths-only` и служебные блоки не входят.

## Пустой bundle

Нулевой набор файлов допустим. Команда завершается с кодом `0`, метаданные содержат `Included files count: 0`, а manifest остаётся пустым.

## Внешние файлы и извлечение

Формат помечает внешний файл как `Kind: external`. Автоматическое извлечение внешних файлов запрещено проектным решением: в будущей реализации каждый такой файл должен выбираться отдельно и получать явно заданный путь назначения. Эта логика отслеживается в issue №4.

## Совместимость

Формат 2 не использует старые искусственные пути `__external__/__parent__/...`. Для минимального вывода доступны совместно `--no-metadata --no-manifest`, но обязательные маркеры версии и границ фрагмента сохраняются.
